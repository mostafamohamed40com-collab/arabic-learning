# رحلة في عالم الضاد

موقع تعليمي ثابت باللغة العربية لدرس **الفعل اللازم والفعل المتعدي**، مناسب للنشر مجانًا على GitHub Pages.

## محتويات المشروع
- `index.html`: هيكل الموقع.
- `css/style.css`: التصميم المتجاوب.
- `js/questions.js`: بنك الأسئلة (15 سؤالًا).
- `js/app.js`: التفاعل والنقاط والشارات وحفظ التقدم.

## قواعد النقاط
- 15 سؤالًا × 20 نقطة = 300 نقطة.
- شارة فارس الضاد: 100 نقطة.
- شارة عبقري النحو: 200 نقطة.
- شارة أمير البيان: 300 نقطة.
- تُحفظ النتائج على نفس المتصفح والجهاز باستخدام `localStorage`.
- السؤالان المفتوحان (14 و15) يعتمدان على التقييم الذاتي بعد قراءة الإجابة النموذجية.

## النشر على GitHub Pages
1. سجّل الدخول إلى https://github.com
2. اضغط **New repository**.
3. اكتب اسمًا مثل `arabic-learning` واجعل المستودع **Public**.
4. اضغط **Create repository**.
5. من صفحة المستودع اختر **Add file → Upload files**.
6. فك ضغط ملف ZIP على جهازك، ثم ارفع محتويات مجلد `Arabic-Learning` نفسها، بحيث يكون `index.html` في جذر المستودع، وليس داخل مجلد فرعي.
7. اضغط **Commit changes**.
8. افتح **Settings → Pages**.
9. تحت **Build and deployment** اختر **Deploy from a branch**.
10. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
11. انتظر دقيقة أو بضع دقائق، ثم افتح الرابط الذي سيظهر في صفحة Pages، غالبًا:
   `https://YOUR-USERNAME.github.io/arabic-learning/`

## ملاحظات
- لا يحتاج الموقع إلى خادم أو قاعدة بيانات.
- التقدم محفوظ على المتصفح الحالي فقط؛ إذا فتح الطالب الموقع من جهاز آخر فلن تنتقل نقاطه معه.
- الخطوط تُحمّل من Google Fonts، لذلك قد يظهر خط بديل عند عدم توفر الإنترنت.
- راجع محتوى الأسئلة مع نسخة كتاب المدرسة المعتمدة قبل الاستخدام الرسمي. صياغة الأسئلة تعليمية أصلية مشابهة لطريقة التدريب وليست نقلًا حرفيًا.
